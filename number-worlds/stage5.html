第2章 STAGE 5

余りのある割り算

互除法とガウス整数
🎯 ミッション
余りのある割り算と互除法から ax＋py＝1 を作り、素数が素元の性質をもつことを証明しよう。ガウス整数でも、余りのノルムを割る数のノルムより小さくできる理由（√2/2 の距離）を説明できれば合格。
未達成
ねこ博士
前のステージで、既約元がどれも素元なら素因数分解はただ1通りになる、と分かった。今日は、整数の素数が素元であることを証明する。道具は割り算だ。17 を 5 で割ると、どうなるかな？
うさ美
17＝5×3＋2 です。商が 3、余りが 2。余りは、割る数の 5 より小さくなります。
ねこ博士
そう。どんな整数 a と 0 でない整数 b でも、a＝qb＋r と書いて、余り r を 0 以上 |b| 未満にできる。これを余りのある割り算という。そして、割る数を余りで割り直すことをくり返すのが、ユークリッドの互除法だ。12 と 7 でやってみよう。12 を 7 で割り、次に 7 をその余りで割り…と、余りが 0 になるまで続けてごらん。
うさ美
12＝7×1＋5、7＝5×1＋2、5＝2×2＋1、2＝1×2＋0。余りは 5, 2, 1, 0 とどんどん小さくなるので、必ずどこかで止まります。最後の 0 でない余りは 1 です。
ねこ博士
その 1 を、途中の式を逆にたどって、12 と 7 だけで書いてごらん。
うさ美
5＝2×2＋1 から 1＝5−2×2。7＝5×1＋2 から 2＝7−5 なので、1＝5−2×(7−5)＝3×5−2×7。12＝7×1＋5 から 5＝12−7 なので、1＝3×(12−7)−2×7＝3×12−5×7。3×12−5×7＝1。12 と 7 に整数を掛けて足し引きしたら、1 が作れました。
余りのある割り算をくり返す：12＝7×1＋5、7＝5×1＋2、5＝2×2＋1、2＝1×2＋0 最後の 0 でない余り 1 を、下から上へたどって書き直す：
1＝5−2×2
＝5−2×(7−5)＝3×5−2×7（2＝7−5 を入れる）
＝3×(12−7)−2×7＝3×12−5×7（5＝12−7 を入れる）
ねこ博士
互除法の最後の 0 でない余りは、2つの数の最大公約数になることが知られている。途中の式を下からたどると、最後の余りが元の2つの数を割り切ることが分かるし、上からたどると、2つの数の公約数は途中の余りを全部割り切ることが分かるからだ。さあ、p を素数、a を p で割り切れない整数とする。何が言えるかな？
うさ美
p の約数は 1 と p だけで、p は a を割り切らないので、p と a の最大公約数は 1 です。だから互除法の最後の余りは 1 で、さっきと同じように逆にたどれば、ax＋py＝1 となる整数 x, y が作れます。
ねこ博士
その式の両辺に b を掛けてごらん。そして、p が ab を割り切るとしよう。
うさ美
abx＋pby＝b。ab は p で割り切れるので abx も p で割り切れ、pby も p で割り切れます。だから左辺は p で割り切れて、右辺の b も p で割り切れます。つまり、p が ab を割り切るとき、p が a を割り切らなければ、b を割り切ります。素数は素元です！ 前のステージの話と合わせると、整数の素因数分解はただ1通りです。
ねこ博士
その通り。この証明で、本当に使った道具は何だったかな？
うさ美
余りのある割り算です。余りが割る数より小さくなるので、互除法が必ず止まって、ax＋py＝1 が作れました。
ねこ博士
そう。では、ガウス整数でも余りのある割り算ができるか考えよう。複素数には大小がないから、「小さい」はノルムで測る。z を w で割って z＝qw＋r と書き、N(r)＜N(w) にできればいい。まず、複素数の割り算 z÷w を考えよう。掛け算は長さを掛けて角度を足したから、割り算は長さを割って角度を引けばいい。具体的に計算するには、分母の w＝2＋i に 2−i を掛けるのが便利だ。(2＋i)(2−i) を計算してごらん。
うさ美
(2＋i)(2−i)＝4−i²＝5。実数になりました。だから、z＝7＋5i を w＝2＋i で割るなら、分母と分子に 2−i を掛けて、(7＋5i)(2−i)/5＝(14−7i＋10i−5i²)/5＝(19＋3i)/5＝3.8＋0.6i です。
ねこ博士
z÷w＝3.8＋0.6i は、ガウス整数ではない。そこで、いちばん近いガウス整数を商 q に選ぶ。q＝4＋i だ。余りを r＝z−qw として計算してごらん。
うさ美
qw＝(4＋i)(2＋i)＝8＋4i＋2i＋i²＝7＋6i。r＝(7＋5i)−(7＋6i)＝−i。N(r)＝1 で、N(w)＝5 より小さいです。これが、いつでもうまくいくんですか？
ねこ博士
それを確かめよう。z÷w は平面のどこかの点で、ガウス整数の点は、1辺 1 の正方形の角に並んでいる。z÷w にいちばん近い角を q に選ぶと、z÷w と q の距離はどこまで大きくなりうるかな？
うさ美
正方形の中で、いちばん近い角がいちばん遠くなるのは、真ん中の点のときです。真ん中から角までは、三平方の定理で √(1/4＋1/4)＝√2/2。だから z÷w と q の距離は √2/2 以下です。余り r＝z−qw＝w×(z÷w−q) の長さは、|w|×（√2/2 以下）。ノルムは長さの2乗なので、N(r)≦N(w)×1/2＜N(w)。余りは必ず小さくできます！
ガウス整数の余りのある割り算。z÷w（赤）を、まわりのガウス整数の格子点（1辺 1 の正方形の角）と一緒に描いた。いちばん近い格子点を商 q（緑）に選ぶと、z÷w と q の距離は、正方形の真ん中のときでも √2/2（点線の円の半径）以下になる。だから余り r＝z−qw のノルムは、いつでも N(w) の半分以下
ねこ博士
その通り。ガウス整数でも余りのある割り算ができるから、互除法が使えて、既約元はどれも素元になり、素因数分解はただ1通りになる。この世界には、フェルマー自身も関わっている。1640年ごろ、フェルマーは手紙に「4 で割って 1 余る素数は、2つの平方数の和で書ける」と書いた。5＝1²＋2²、13＝2²＋3² のようにね。この事実は、ガウス整数の一意性を使ってきれいに証明できるんだ。
うさ美
13＝2²＋3² なら、ガウス整数では 13＝(3＋2i)(3−2i) と分けられるということですね。整数の素数が、ガウス整数の世界で2つの部品に分かれるときが、2つの平方数の和になるときなんですね。
ねこ博士
そう。では最後に、この割り算が a＋b√−5 の世界でもできるのか。次のステージで、ついにラメの証明が崩れた理由にたどり着く。
もっとくわしく互除法の最後の余りが最大公約数になる理由、ax＋by＝1 と mod p の逆元のつながり、ガウス整数の割り算から既約元が素元になるまでの道筋は、『群・環・体からガロア理論へ』の『第2章 STAGE4 余りのある割り算』で、途中を省かずに説明している。ここで名前だけ出した「4 で割って 1 余る素数は2つの平方数の和」は、『第2章 STAGE5 2つの平方数の和』でガウス整数の一意性を使って実際に証明している。
【このステージの成果】 余りのある割り算：a＝qb＋r、余りは割る数より小さい。これをくり返すのがユークリッドの互除法 互除法を逆にたどると 3×12−5×7＝1 のような式ができる。p が素数で a を割り切らなければ ax＋py＝1 両辺に b を掛けて abx＋pby＝b → p が ab を割り切れば b を割り切る → 素数は素元 → 整数の素因数分解はただ1通り ガウス整数の割り算：z÷w にいちばん近い格子点を q にすると、距離は √2/2 以下 → N(r)≦N(w)/2 ガウス整数でも互除法が使え、素因数分解はただ1通り。4 で割って 1 余る素数は2つの平方数の和（フェルマー）

確認クイズ

Q1. 12 と 7 の互除法を逆にたどって得られる式は？

正解！ 1＝5−2×2＝3×5−2×7＝3×12−5×7。互除法の最後の 0 でない余り（最大公約数）は、元の2つの数に整数を掛けて足し引きした形で書ける。

Q2. 素数 p が ab を割り切り、a を割り切らないとき、p が b を割り切る理由は？

正解！ p と a の最大公約数は 1 なので ax＋py＝1 と書ける。b を掛けると abx＋pby＝b。ab も p も p で割り切れるので、b も p で割り切れる。

Q3. ガウス整数の割り算で、余り r のノルムが必ず N(w) より小さくなる理由は？

正解！ 格子は1辺 1 の正方形。いちばん遠いのは真ん中で、角まで √2/2。r＝w×(z÷w−q) の長さは |w|×√2/2 以下なので、ノルムは N(w)/2 以下。
